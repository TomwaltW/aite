## 10. 契约缺口（给 T0 / T0.1）

**`NetworkEvent`**（请 `domain.rs` 逐字段对齐，能反序列化本包写出的行）：

| 键 | JSON 类型 | Go 类型 | 说明 |
|---|---|---|---|

| `audit_tag` | string | `string` | 令牌不对时 `""` |

| `reason` | string | `string` | 原因码；放行为 `""`；`upstream_error` 时 decision=allow |
| `status` | integer | `int` | |
| `bytes_up` | integer | `int64` | |
| `bytes_down` | integer | `int64` | |
| `duration_ms` | integer | `int64` | |

文件名：`<AuditDir>/YYYYMMDDHH.jsonl`，小时按 UTC；一行只进它 `ts` 所在小时的文件。
注意：`level` 在令牌不对时是空串，不是四个档位之一——Rust 侧若用枚举反序列化，要给空串留位置（`Option` 或 `#[serde(default)]` + 空值变体），否则 407 行反序列化失败。
`reason` 同理是开放字符串（8 个原因码 + 空串）。

**`Level` ↔ `SandboxNetwork`**：`"none"` ↔ `None`、`"trusted"` ↔ `Trusted`、`"custom"` ↔ `Custom`、`"full"` ↔ `Full`（线上字符串逐一相同）。

`Credentials` ↔ `credentials`、`AuditTag` ↔ `audit_tag`。`CredentialBinding{Host, Header, Scheme, SecretRef}` ↔ `{host, header, scheme, secret_ref}`。
`allow_hosts` 的模式语法（精确 / `*.后缀`、可带端口、无端口 = 80/443、禁 `*`）建议写进契约注释，DD6 拼策略时照它。
