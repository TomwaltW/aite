**云端测试基底（不入库，所有云端 docker 数字都带这个前提）**：为了在云端真跑 20 条 unittest、4 条新 Go 用例和镜像级变异，
在 scratchpad 里建了一个派生基底并本地重打成 `python:3.11-slim`：

```
FROM python@sha256:e41613d42d4891e4930f79523f93f81bbc7632584ec65e36ab055f41a800b41e
COPY ca-bundle.crt /etc/aite-cloud-ca-bundle.crt      # 会话出口代理的 CA 包
COPY pip.conf /etc/pip.conf                           # 只有 [global] cert = /etc/aite-cloud-ca-bundle.crt
```

不设任何 `ENV`（`Config.Env` 与上游逐字相同，不影响 `test_no_proxy_env_in_image`）；沙箱 Dockerfile 在 `pip install` 之后 COPY 自己的
`/etc/pip.conf` 把它盖掉。沙箱 Dockerfile 本身一个字没为云端改。**这不等于默认构建**：默认构建（真 Docker Hub 基底 + 真 PyPI）以 CI 的
`sandbox-docker` 与总管本机为准，标「人工本机量」。
