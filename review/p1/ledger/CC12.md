## 3. 给 DD5 / EE12 / FF6 的接口

**CLI**（原样）：

```
python /opt/aite/aite_label.py [--producer 名] [--produce-id ID] [--propagator 名] [--propagate-id ID] [--watermark] <路径>...
```

不带参数的默认值：`Label="1"`、`ContentProducer="Aite"`、`ProduceID=uuid4().hex`（**一次调用生成一个，同批各文件共用**）、`ContentPropagator=""`、`PropagateID=""`。

**退出码**：

| 码 | 含义 | 调用方判定 |
|---|---|---|
| 0 | 全部已标 | 成功 |
| 3 | 有跳过、无错误（不支持的扩展名 / 镜像里没有 pypdf） | **成功** |
| 1 | 有文件出错（不存在、内容与扩展名不符、解析失败…） | 失败 |
| 2 | 用法错（argparse 默认，如没给路径） | 失败 |

**0 / 3 算成功，1 / 2 算失败**——DD5 不能拿 `returncode != 0` 判失败。

**输出行样例**（镜像里真跑的）：

```
$ python /opt/aite/aite_label.py x.png r.md d.csv; echo "rc=$?"

{"path": "r.md", "format": "markdown", "status": "labeled", "reason": ""}
{"path": "d.csv", "format": "csv", "status": "skipped", "reason": "不支持的类型（csv），不打隐式标识"}
rc=3
$ python /opt/aite/aite_label.py; echo "rc=$?"

                     [--propagator PROPAGATOR] [--propagate-id PROPAGATE_ID]

**import**：`sys.path.insert(0, "/opt/aite"); import aite_label`

- `label_file(path, fields=None, watermark=False) -> dict`：返回与 CLI 同形的 `{"path","format","status","reason"}`，不抛异常；`fields` 只认 5 个键（缺的用默认值补，多的 → `status=error`）。
- `read_label(path) -> dict | None`：读回 5 个字段；没标过 / 不支持 / 读不出返回 `None`。
- 另有 `make_fields(...)`、`exit_code_for(results)`、常量 `AIGC_KEYS` / `XMP_NS` / `PDF_SKIP_REASON`。

**各格式写在哪（终稿）**：载荷一律是 5 个键、值全字符串的紧凑 JSON（`ensure_ascii=False`；EXIF 那份 `ensure_ascii=True`）。

| 格式 | 扩展名 | 写入位置 | 读回 | 备注 |
|---|---|---|---|---|
| PNG | `.png` | `iTXt` 块，keyword `AIGC`，UTF-8，未压缩（pillow `PngInfo.add_itxt`） | `tEXt` / `iTXt` / `zTXt` 都认 | 原有文字块（如 matplotlib 的 `Software`）与 `icc_profile` / `dpi` / `transparency` / `gamma` 保留；PNG 无损，像素逐字节不变 |
| JPEG | `.jpg` `.jpeg` | ① XMP（APP1，`http://ns.adobe.com/xap/1.0/`）里 `rdf:Description` 的属性 `TC260:AIGC`，命名空间 `http://www.tc260.org.cn/ns/AIGC/1.0/`（**第三方解读**）；② EXIF IFD 的 `UserComment`（0x9286），`ASCII\0\0\0` + ASCII JSON | 先读 XMP，再退 EXIF | **按字节换 APP1 段，SOS 之后的扫描数据原样保留 → 不重压缩**；已有 EXIF 其它标签保留，已有 XMP 就往里并这一个属性 |
| DOCX / XLSX / PPTX | `.docx` `.xlsx` `.pptx` | `docProps/custom.xml` 里 `name="AIGC"` 的 `vt:lpwstr`（fmtid `{D5CDD505-2E9C-101B-9397-08002B2CF9AE}`） | 同 | 没有就新建，并给 `[Content_Types].xml` 加 `/docProps/custom.xml` 的 Override、给 `_rels/.rels` 加 custom-properties 关系（Id 取第一个空闲 `rIdN`）；已有就合并，`pid` 从现有最大值往上接；标两次不重复 |
| Markdown | `.md` `.markdown` | 文件头 YAML front-matter 的 `AIGC: '<JSON>'`（单引号，`'` 转义成 `''`） | 同 | 没有 front-matter 就加；已有就只增 / 换这一个键（连同它的缩进续行），BOM 保留 |
| PDF | `.pdf` | 文档信息字典 `/AIGC`（pypdf `PdfWriter(clone_from=…)` + `add_metadata`） | 同 | pypdf 缺 → `skipped`，reason「镜像里没有 pypdf（D12 未批），PDF 不打隐式标识」，退出码 3。本镜像装了 pypdf 6.19.0 |
| 其它 | — | 不动文件 | `None` | `skipped`，退出码 3 |

**pillow 11.0.0 实测**（镜像内 `inspect.getsource(JpegImagePlugin._save)`）：`xmp=` 与 `quality="keep"` **都支持**。但 `quality="keep"` 仍是解码再按原量化表重编码，
所以不用它：JPEG 走按字节插 APP1 段，零重压缩（`test_jpeg_exif_and_xmp_roundtrip` 断言 SOS 之后逐字节不变）。只有 `--watermark` 时像素本来就要变，才以 `quality=95` 重编码一次。
另一个实测坑：pillow 11.0.0 的 `Exif.tobytes()` 在 0x8769 不在顶层时会丢掉 `get_ifd()` 上的修改，所以写法是把子 IFD 当 dict 显式塞回顶层（代码里有注释）。

**进 `files_out`**：标识是「同目录临时文件 + `os.replace`」，标完文件的 size / mtime 都变，所以它会出现在**调标识器那次 Exec** 的 `files_out` 里
（`docker.go` 按快照差集算）——DD5 在同一次 `run_python` 里先生成再标，或单独一次 Exec 标，都会看到它；临时文件以 `.aite_label.` 开头、成功后不留。
